# React - Spotify Clone

This project is clone of Spotify created using React + Vite. Audio db is stored in assets. Customized Audio seekbar is also present. Css is applied using Tailwind library.

## Tailwind CSS
- Install tailwind from [Tailwind installation](https://tailwindcss.com/docs/installation/using-vite)
- Follow notations decided by tailwind to apply css on elements

## Custom Audio Seekbar
- ```Cutomized seekbar``` is present that represents current time of audio. This seekbar can be slided forward or backward and audio will reflect the changes.
- Furthermore, audio can be played , paused, previuos or next using ````custom player options````

### Using React features
- Various hooks like ```useState```,```useContext```,```useRef```,```useCallback``` have been used.
- ```Events' properties``` have been used for complex calculation for time and seekbar related calculations
